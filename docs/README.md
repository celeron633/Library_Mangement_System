# 图书管理系统

大学课程设计项目 - 基于C++（C with Class）实现的图书管理系统

## 项目简介

这是一个功能完整的图书管理系统，支持用户管理、图书管理、购买等核心功能。系统提供了管理员和普通用户两套不同的操作界面。

## 主要功能

### 用户管理
- 用户注册和登录
- VIP会员功能
- 账户余额充值
- 用户信息管理

### 图书管理（管理员）
- 添加/删除图书
- 编辑图书信息（价格、库存等）
- 查询图书详情
- 按价格排序查看图书列表

### 图书购买（普通用户）
- 浏览可购买图书列表
- 通过ID购买图书
- 查看购物车和账户余额

### 系统管理
- 管理员创建和登录
- 用户/图书数据持久化存储
- 清屏菜单界面

## 编译方法

### 前置要求
- CMake >= 3.10
- C++17编译器（GCC/G++）

### Linux 编译
```bash
# 创建构建目录
mkdir build
cd build

# 生成构建文件并编译
cmake ..
make

# 运行程序
./main
```

### Windows 编译
```bash
# 创建构建目录
mkdir build
cd build

# 生成Visual Studio项目（以VS2019为例）
cmake .. -G "Visual Studio 16 2019"

# 编译
cmake --build . --config Release

# 运行程序
.\Release\main.exe
```

## 项目结构

```
.
├── CMakeLists.txt      # CMake编译配置
├── main.cpp            # 主程序文件（包含菜单和逻辑）
```

## 文件说明

- **main.cpp**：核心代码，包含用户系统、图书管理、购买流程等所有业务逻辑
- **utils.cpp**：辅助工具函数（如清屏等）
- **CMakeLists.txt**：CMake构建配置文件

## 数据存储

系统支持数据持久化，相关数据存储在本地文件中：
- 用户信息文件
- 图书信息文件
- 管理员信息文件
